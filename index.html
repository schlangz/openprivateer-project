FILE 01

PROJECT OVERVIEW

Rebuilt from the inside out.

MISSION BRIEFING

OpenPrivateer is a clean modern engine for the original Privateer experience. It reads the real game data and recreates the systems, interfaces, cutscenes, music, missions, bases and spaceflight behavior of the original game.

DESIGN DIRECTIVE

The goal is not to replace Privateer with a different game. The project first aims to reproduce the original experience faithfully, then adds carefully separated quality-of-life, enhanced and modding options.

FILE 08

FAQ

Before you launch.

Is OpenPrivateer a remake?

It is a modern reimplementation of the Privateer engine that uses the original game data.

Does it include the original assets?

No, OpenPrivateer does not distribute copyrighted game assets. You must provide the original game data from a copy you own.

Can I download it now?

Not yet. The first public downloads are planned for the September development update.

Will it support widescreen and HD?

Yes, but those features will develop gradually alongside the core game. Faithful 320x200 behavior remains the immediate priority.

Will there be modding support?

Yes. Content overrides and translation already exist (original PAK and IFF format), with broader modding capabilities (bases, planets, ships, etc.) planned over time.

What about multiplayer?

A technical concept for multiplayer setup exists but is not part of the implementation plan yet.
