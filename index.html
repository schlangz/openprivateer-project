ABOUT THE PROJECT

About OpenPrivateer

WHAT IT IS

OpenPrivateer brings the original Wing Commander: Privateer to modern systems. It uses the original game files and aims to recreate everything from spaceflight and combat to missions, conversations, music and cutscenes as faithfully as possible.

THE APPROACH

The original game comes first. Once everything works as it should, OpenPrivateer can build on that with optional improvements, modern features and modding support. Players who prefer the classic experience can keep it that way.

PROJECT OVERVIEW // PUBLIC BETA

OpenPrivateer recreates the original Privateer and Righteous Fire using the games' original data. Both original single-player campaigns are fully playable from beginning to end in a native modern engine, including their stories, missions, combat, trading and bases.

FAITHFUL TO THE ORIGINAL

Classic mode focuses on authentic gameplay. Original DOS save files can be read and written, with additional OpenPrivateer state stored separately so the original format stays intact.

ROOM TO EXPLORE

Enhanced and Modern modes offer optional additions such as multiple ships, hired wingmen, expanded equipment and stealth systems. Open Universe and mod support allow creators to go further without changing the classic experience.

PLAY TOGETHER

Online multiplayer includes dedicated servers, a server browser, shared space combat, trading, missions, hired wingmen and chat. Public community servers are available for testing. See multiplayer details.

OpenPrivateer is now in public beta. Both original campaigns are fully playable; multiplayer and some optional enhancements are still being tested and refined. Check the development status or download a build.

  1. Download and extract OpenPrivateer.
  2. Start openprivateer.exe on Windows, or the corresponding executable on Linux or macOS.
  3. The launcher opens. Select Privateer or Righteous Fire at the top.
  4. Open Game Data and provide the original game files:
    • Privateer: PRIV.TRE and INITCFG.PAK

MULTI 02

MULTIPLAYER

Client & Server.

JOIN THE PUBLIC TEST

Fly with other pilots on community-hosted servers in Europe and North America. Multiplayer features shared spaceflight, server-authoritative PvE/PvP combat, missions, trading, wingmen and chat. This is still a beta test: expect bugs and occasional incompatibilities between builds.

JOIN A SERVER

  1. Install the latest OpenPrivateer build and configure your original game data in the launcher.
  2. Open Multiplayer > Browse Servers > Internet in the launcher.
  3. Select a public server and enter its password if requested. If you need it, ask on our Discord.
  4. Launch the game, then select NEW or LOAD to join.

Press Y (Z on German keyboards) for global chat, or use the original Communications MFD to contact another pilot privately. Your saves remain local; flight and combat are handled by the server.

HOST YOUR OWN SERVER

OpenPrivateer includes a headless dedicated server and launcher hosting options. For server configuration, port settings and command-line examples, see the player manual.

MODDING

Modding and game data

CREATE & EXPAND

Mods can introduce new ships, weapons, equipment, missions, starting conditions, systems, jump routes, bases and other gameplay changes. OpenPrivateer also supports real 3D ship models and widescreen cockpit mods. Equipment modifiers cover handling, shields, armour, power, guns, stealth and specialized ship systems.

INSTALL & CUSTOMIZE

Use INSTALL MOD... in the launcher or drag files and folders onto it. Supported formats include ZIP, RAR, 7z and TAR variants. Players can also replace local art, sounds and translations, install widescreen cockpit artwork, and use real 3D ship models.

FILE 08

FAQ

Frequently asked questions

Is OpenPrivateer a remake?

Not quite. It's a new engine built to recreate the original Privateer as closely as possible, using the original game data.

Does it include the original game files?

No. You'll need your own copy of Wing Commander: Privateer. OpenPrivateer doesn't include any of the original copyrighted game files.

Can I download it already?

Yes! The public beta is available in the Downloads section. Both original campaigns are fully playable, although bugs and experimental features remain.

Will there be widescreen and HD support?

Real 3D ship models and widescreen cockpits are already supported through mods. The original 320x200 presentation remains available, with optional scaling and display filters.

What about VR?

VR remains a longer-term possibility, but it is not currently a standard supported feature.

Can I make mods?

Yes! You can already replace game assets, add translations, and modify various parts of the game using the original PAK and IFF formats. Support for things like custom ships, bases, and star systems is being expanded.

What can I do in multiplayer?

You can join public or private dedicated servers, fight NPCs and other players, trade, complete missions, hire wingmen and chat. Multiplayer remains in public testing, and some features may have limitations.

Edwin Herrell, another member of the original Privateer development team, generously shared firsthand insight into the game's flight model, including its damping behavior, simulated weapon-fire projectiles and lead calculation, and target collision checks. His explanations helped us better understand the original code, clear up some unanswered questions, and confirm parts of our reverse engineering. Thanks to Edwin for sharing his knowledge and helping us better understand the original game.
